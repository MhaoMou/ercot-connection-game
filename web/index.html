About network data

Public transmission geography comes from the public HIFLD transmission layer; generation context comes from EIA Form 860 (2025). Lines are geographic context only. The Planning Model is a versioned instructional abstraction with Planning Regions, Planning Interfaces, and deterministic teaching conditions; it is not an operational ERCOT bus-branch model or interconnection study.

HIFLD source · EIA Form 860 · Full provenance is recorded in the Gate 5 planning-model report.

Connection sites

Capacity: finite, non-negative MW; example 10. Profile: 0–1 per period; example [1, 1, 0.8, 0.8, 1, 1]. Select any path corridors shared by this site.

Generators

Generator model. A generator is a site-attached supply option; the server decides dispatch order and cost.

How to add a generator

Add one card per generator, choose a current connection site, and use a non-negative capacity and marginal cost.

Generators attach to a connection site. Capacity: finite, non-negative MW. Generator cost: finite, non-negative $/MWh; example 80.
