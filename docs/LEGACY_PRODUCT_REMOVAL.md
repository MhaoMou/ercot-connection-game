# Legacy Product Removal

The repository previously contained a browser practice application and an
abstract six-period teaching-network evaluator. Those materials are retained
under `archive/legacy/` solely for provenance and recovery.

They are not installed as package entry points, included in the active test
suite, imported by the production batch evaluator, or described as the current
game. The active product is the Zenodo source-bus CSV evaluator documented in
`README.md` and `docs/ERCOT_INSTRUCTOR_BATCH_EVALUATION.md`.
